W Wrava

A local-first writing tracker.
Strava, for your prose.

Wrava turns a folder of ordinary Markdown files into a writing practice you can see. Every accepted change is measured as words added, words deleted, and net document growth, all stored on your own machine.

Try the live demo View on GitHub

See your writing practice

A calm, distraction-light editor paired with an analytics page that turns raw edits into a 12-week trend, a consistency heatmap, and per-document and per-tag breakdowns.

What's in the current vertical slice

Wrava is an early, actively developed project.

  • Select and index a folder of Markdown files
  • Create and safely rename Markdown files
  • Write in a WYSIWYG-style rich editor over plain Markdown
  • Switch to a full Markdown source editor
  • Apply headings, bold, italic, underline, and link formatting
  • Add portable comma-separated tags in YAML front matter
  • Reconcile changes made in other editors
  • Record words added, words deleted, and net growth locally
  • See activity for today, this week, this month, and this year
  • Explore a 12-week trend, heatmap, and per-tag breakdowns
